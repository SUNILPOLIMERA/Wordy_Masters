# Wordy Masters

Wordy Masters is a lightweight word-based project designed to explore interactive text manipulation and wordplay logic.  
This repository contains the core files for running the project in a browser environment.

---

## 📂 Project Structure

- **index.html** – Entry point of the application, sets up the UI.
- **style.css** – Stylesheet for layout and design.
- **master.js** – Main JavaScript logic powering the word interactions.

---
